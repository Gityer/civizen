# Study learning paths

Phase 5 of the implementation plan (decision D4: real learning paths with progress; no tests or schedules until a person writes them).

## What exists

- Three paths at `/study/paths`, five lessons each, in the Study secondary navigation ("Learning paths"); `/study/courses` redirects there.
  - `charter-and-pathway` from `docs/00-foundation/the-civizen-charter.md` and `recognized-planetary-citizenship-pathway.md`.
  - `how-civizen-decides` from `docs/02-policies/governance/civizen-community-governance-charter.md` and `docs/01-governance/participation/civic-voting-system-design-v0.1.md` §12–15.
  - `rights-and-duties` from `docs/01-governance/participation/citizen-status-model-v0.1.md`, the Governance Charter and Settings › Account.
- Text is curated in EN, HY and RU (`src/lib/study/paths/<path>.<locale>.ts`); other languages read English. Lesson ids are shared across locales; the test enforces it.
- Each reader lists its sources (`LEARNING_PATH_SOURCES`), linking to the site page when one exists.

## Progress

- Completed lessons: `study_progress` rows keyed `path:<path>:<lesson>` (unique per member and key), written only through `mark_study_lesson_complete(path, lesson, path_lesson_keys)`; a key outside the path is refused.
- Completed path: `study_certifications` row `path:<path>` with status `earned`, awarded by the same function when every lesson key is complete.
- Public profile: `public_study_completions(profile)` returns earned `path:*` certifications of live members; `StudyCompletionBadges` renders them on `/user/:id`.

## Rules for changing a path

- Edit the source document first, then the lesson text; keep the institutional boundary sentences (not a government, does not claim, AI cannot authorize emergency action).
- Adding or renaming a lesson changes the lesson keys: members keep completed lessons they already have, and a path completes when all current keys are done.
- Do not add quizzes or schedules generated by software; a knowledge check needs a human author (D4).
