# Contribute Page Redesign
**Project:** Civizen  
**Page:** Contribute  
**Version:** 2.0  
**Status:** Superseded on 2026-10-09 by the shipped Contribute hub (Matters, Opportunities, Challenges, Knowledge, Impact); kept as design history

---

# Objective

Redesign the **Contribute** page from a collection of shortcuts into the primary hub where individuals and organizations can contribute to the Civizen ecosystem and the mission of building a Mature Humanity.

The current implementation duplicates functionality that already exists elsewhere in the application (Profile, Messaging, Score, etc.) and therefore provides little value.

The redesigned page should answer one simple question:

> **"How would you like to contribute today?"**

This page should become the central place where people can:

- Volunteer
- Contribute professional skills
- Support financially
- Join community projects
- Complete meaningful tasks
- Share knowledge
- Improve Civizen
- Partner as an organization
- Track their impact

---

# Design Principles

The page should:

- Inspire participation
- Encourage contribution
- Show meaningful opportunities
- Scale from individual users to governments
- Connect needs with contributors
- Reflect Civizen's mission rather than user profile management

This page is **not** intended to replace existing functionality. Instead, it should become the gateway directing users toward meaningful contributions across the platform.

---

# Remove Existing Cards

Remove the following cards:

- Endorse someone
- Improve your profile
- Share an update
- Review your score

These already exist in their appropriate locations:

| Current Card | Existing Location |
|--------------|------------------|
| Endorse someone | User Profiles |
| Improve profile | Profile |
| Share update | Messaging |
| Review score | Profile / Score |

The Contribute page should not duplicate existing navigation.

# Guiding Principle

The Contribute page should become **the engine of participation** within Civizen.

Rather than acting as a navigation shortcut, it should connect people, organizations, communities, and institutions with meaningful opportunities to improve society.

Every contribution—whether time, expertise, funding, knowledge, or leadership—should begin here.

Ultimately, this page should evolve into a global marketplace where every need can find someone willing and able to help, and every person or organization can discover meaningful ways to contribute toward a more mature, cooperative, and peaceful humanity.
